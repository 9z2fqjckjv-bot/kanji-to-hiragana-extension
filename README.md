# 漢字→ひらがな変換（Chrome拡張機能）

Webページ上の**漢字仮名交じり文**を、学習用に**ひらがな中心の表記**へ変換する Manifest V3 拡張機能です。

例: `漢字仮名交じり文` → `かんじかなまじりぶん`

既存のひらがな・カタカナ・数字・英字・句読点はそのまま残します。

## 機能概要

- ポップアップで**現在のタブだけ**オン／オフ（初期状態はオフ）
- 表示テキストノードを走査して漢字をひらがな読みに置換
- `script` / `style` / `noscript` / `textarea` / `input` / `code` / `pre` などは対象外
- リンクはそのままクリック可能
- オン中は `MutationObserver` で動的追加テキストにも追従
- オフにすると元のテキストを復元（復元できない場合はページ再読み込みが安全）
- 読み変換は **kuroshiro + kuromoji**（辞書を拡張に同梱、インストール後はオフライン利用可）

## 事前準備（ビルド）

辞書ファイルが大きいため、リポジトリにはソースを置き、次のコマンドで読み込み可能な `dist/` を生成します。

```bash
cd kanji-to-hiragana-extension
npm install
npm run build
```

成功すると `dist/` に次が含まれます。

- `manifest.json`
- `content.js` / `background.js` / `popup.js`
- `popup.html` / `popup.css`
- `icons/`
- `dict/`（kuromoji 辞書）

## Chrome への読み込み（未パッケージ化）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」
4. このプロジェクトの **`dist`** フォルダを選択
5. ツールバーにアイコンが表示されれば完了

## 使い方

1. 変換したい Web ページを開く
2. 拡張機能アイコンをクリック
3. 「オンにする」を押す（初回は辞書読み込みで数秒かかることがあります）
4. ページ上の漢字がひらがなに置き換わります
5. 「オフにする」で元の文言に戻します

**対象:** 通常の http(s) ページ  
**対象外:** `chrome://` などの内部ページ、Chrome ウェブストア、拡張機能ページなど

## 開発用コマンド

```bash
npm install          # 依存関係のインストール
npm run build        # dist/ を生成
npm run smoke-test   # Node 上で変換ロジックの簡易確認
npm run dev          # 監視ビルド（開発用）
```

## アーキテクチャ（簡潔）

| 部品 | 役割 |
|------|------|
| `background.js` | タブごとのオン／オフ状態、コンテンツスクリプト注入 |
| `content.js` | テキストノード走査・置換・MutationObserver・復元 |
| `converter`（content 内） | kuroshiro で漢字→ひらがな |
| `popup.*` | 日本語 UI（オン／オフ） |
| `dict/` | kuromoji 形態素解析辞書（ビルド時にコピー） |

状態は**タブ単位**です。別タブには自動では効きません。ページを遷移しても、そのタブでオンのままなら再適用を試みます。

## 既知の制限

- 固有名詞・当て字・文脈依存の読みは誤ることがあります（形態素解析の限界）
- 非常に大きなページでは初回変換に時間がかかることがあります
- 一部の特殊なサイト（Shadow DOM 多用、キャンバス文字、画像文字）は対象外または不完全
- `contenteditable` や入力欄は意図的に変換しません
- オフ時は可能な範囲で原文を復元しますが、サイト側が同時に DOM を書き換えた場合は不完全になり得ます。そのときはページ再読み込みしてください
- 拡張の `dist/` サイズは辞書込みで数十 MB 程度になります

## ライセンス上の注意

- 本拡張のソースはリポジトリのライセンスに従います
- **kuromoji / kuroshiro** および辞書データには各パッケージのライセンス条件があります。再配布時は `node_modules` 内のライセンス表記を確認してください

## トラブルシューティング

- オンにしても変わらない → ページを再読み込みしてから再度オン
- 「このページでは使えません」→ Chrome 内部ページではないか確認
- ビルド失敗 → Node.js 18+ を使い、`npm install` を再実行
